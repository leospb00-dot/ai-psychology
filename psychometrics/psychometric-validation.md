## 1. PATIENTS' ENDORSEMENT OF BIOPSYCHOSOCIAL MODEL SCALE (PEB)

- **Kleinstuber, M. et al. (2023)**: Pain Medicine (IF: 3.4) - Validation of PEB Scale [37]
- **Sanyer, M.M. (2025)**: Clinical Psychology Review (IF: 13.7) - PEB Scale validation in young adults [40]

### Психометрические свойства

#### Факторная структура
- **Модель**: Унидимензиональная структура с 11 пунктами [37]
- **Объясненная дисперсия**: 51.2% общей дисперсии [37]
- **Факторный анализ**: Метод главных компонент подтвердил однофакторную модель [37]

#### Надежность
- **Внутренняя консистентность**: Cronbach's α = 0.92 (отличная надежность) [37]
- **Split-half надежность**: r = 0.867 [4]
- **Test-retest надежность**: r = 0.823 (p < 0.001) через 4 недели [4]

#### Валидность

**Конвергентная валидность**:
- **PSS-10**: r = 0.714 (p < 0.001) - умеренная положительная корреляция [4]
- **SWLS**: r = -0.612 (p < 0.001) - умеренная отрицательная корреляция [4]
- **PHQ-9**: r = 0.683 (p < 0.001) - умеренная положительная корреляция [4]

**Предиктивная валидность**:
- **Готовность к самоуправлению болью**: Сильный предиктор (p < 0.001) после контроля демографических переменных, тревоги и депрессии [37]
- **Интегрированные вмешательства**: Предсказывает готовность к мультидисциплинарному подходу [37]

#### Клиническое применение
- **Пороговые значения**: Cut-off 2.45 балла (оптимальный баланс чувствительности и специфичности) [4]
- **ROC анализ**: AUC = 0.761 (95% CI: 0.728-0.794) [4] 
- **Чувствительность**: 73.2% [4]
- **Специфичность**: 71.8% [4]

### Интеграция в алгоритм
```python
def calculate_peb_score(responses):
    # 11 пунктов, шкала 1-5
    # Высокие баллы = большее принятие биопсихосоциальной модели
    total_score = sum(responses) / 11  # Средний балл
    
    # Нормализация (z-score)
    population_mean = 3.2  # Нормативное среднее
    population_sd = 0.8    # Стандартное отклонение
    
    peb_z = (total_score - population_mean) / population_sd
    return peb_z
```

### Интеграция в алгоритм
```python
def calculate_bfi2_personality_index(domain_scores):
    # domain_scores: словарь с 5 доменными оценками
    # Каждый домен 1-5 баллов (12 пунктов по 1-5)
    
    # Нормализация доменов (популационные нормы M=3.0, SD=0.7)
    normalized_domains = {}
    population_mean = 3.0
    population_sd = 0.7
    
    for domain, score in domain_scores.items():
        domain_mean = score / 12  # Средняя оценка по домену
        normalized_domains[domain] = (domain_mean - population_mean) / population_sd
    
    # Взвешенная комбинация для психического здоровья
    # Отрицательные веса для негативных предикторов
    weights = {
        'negative_emotionality': 0.4,    # Наибольший вес (риск)
        'conscientiousness': -0.2,       # Протективный фактор
        'agreeableness': -0.15,          # Протективный фактор  
        'extraversion': -0.15,           # Протективный фактор
        'open_mindedness': -0.1          # Слабый протективный фактор
    }
    
    personality_risk_index = sum(weights[domain] * z_score 
                                for domain, z_score in normalized_domains.items())
    
    return personality_risk_index
```

## 5. ИТОГОВЫЙ ПСИХОМЕТРИЧЕСКИЙ ИНДЕКС

### Алгоритм интеграции (вес 0.30 в общей модели)
```python
def calculate_psychometric_component(peb_responses, phq9_score, gad7_score, bfi2_scores):
    # Рассчет индивидуальных компонентов
    peb_index = calculate_peb_score(peb_responses)
    phq9_index = calculate_phq9_index(phq9_score) 
    gad7_index = calculate_gad7_index(gad7_score)
    personality_index = calculate_bfi2_personality_index(bfi2_scores)
    
    # Веса подкомпонентов психометрии
    weights = {
        'depression': 0.35,      # PHQ-9 (наибольший клинический вес)
        'anxiety': 0.30,         # GAD-7  
        'personality': 0.25,     # BFI-2 (долгосрочные паттерны)
        'biopsych_endorsement': 0.10  # PEB (готовность к лечению)
    }
    
    # Итоговый психометрический индекс
    psychometric_index = (
        weights['depression'] * phq9_index +
        weights['anxiety'] * gad7_index + 
        weights['personality'] * personality_index +
        weights['biopsych_endorsement'] * peb_index
    )
    
    return psychometric_index
```

### Клиническая интерпретация
- **Индекс > +2.0**: Высокий психометрический риск
- **Индекс +1.0 to +2.0**: Умеренно-высокий риск
- **Индекс 0.0 to +1.0**: Умеренный риск  
- **Индекс -1.0 to 0.0**: Низкий риск
- **Индекс < -1.0**: Протективный психометрический профиль

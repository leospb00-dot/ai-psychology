### 1.4 Формула расчета ИЭС

```python
def calculate_EMS(digital_overload, social_isolation, circadian_disruption, 
                  nature_deficit, physical_inactivity):
    """
    Расчет Индекса Эволюционного Стресса (ИЭС)
    
    Все входные параметры должны быть стандартизированы (z-scores)
    """
    weights = {
        'digital': 0.28,
        'social': 0.25,
        'circadian': 0.22,
        'nature': 0.15,
        'physical': 0.10
    }
    
    ems_score = (
        weights['digital'] * digital_overload +
        weights['social'] * social_isolation +
        weights['circadian'] * circadian_disruption +
        weights['nature'] * nature_deficit +
        weights['physical'] * physical_inactivity
    )
    
    return ems_score
```

### 2.4 Алгоритм расчета ИИА

```python
def calculate_IAI(biomarkers_z, psychometry_z, digital_pheno_z, social_metrics_z):
    """
    Расчет Интегрального Индекса Адаптации (ИИА)
    
    Входные параметры - стандартизированные z-scores
    Выход - вероятность положительного исхода (0-1)
    """
    weights = [0.35, 0.30, 0.25, 0.10]
    features = [biomarkers_z, psychometry_z, digital_pheno_z, social_metrics_z]
    
    linear_combination = sum(w * f for w, f in zip(weights, features))
    
    # Логистическое преобразование
    probability = 1 / (1 + np.exp(-linear_combination))
    
    return probability
```

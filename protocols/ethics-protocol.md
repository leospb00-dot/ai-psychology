# Этический протокол для интегральной биопсихосоциально-эпигенетической модели

## 1. Нормативно-правовая база

### 1.1 Международные стандарты

**Обязательное соответствие:**
- Declaration of Helsinki (2013) - принципы медицинских исследований с участием человека
- International Council for Harmonisation Good Clinical Practice (ICH-GCP)
- Council for International Organizations of Medical Sciences (CIOMS) Guidelines
- UNESCO Universal Declaration on Bioethics and Human Rights (2005)

**Национальные требования:**
- FDA Title 21 Code of Federal Regulations (США)
- EMA Clinical Trials Regulation EU No 536/2014 (Европа)
- ФЗ-323 "Об основах охраны здоровья граждан" (Россия)
- ФЗ-152 "О персональных данных" (Россия)

### 1.2 Специфические стандарты для генетических данных

**Генетическое тестирование:**
- American College of Medical Genetics (ACMG) Guidelines
- European Society of Human Genetics (ESHG) Recommendations
- Genetic Information Nondiscrimination Act (GINA) - защита от дискриминации
- Clinical Laboratory Improvement Amendments (CLIA) - стандарты лабораторий

## 2. Информированное согласие

### 2.1 Многоуровневое согласие

**Уровень 1: Базовое участие**
```
Согласие на:
✓ Клинические опросы и интервью
✓ Физикальное обследование
✓ Стандартные лабораторные тесты
✓ Анонимизированное использование данных в исследовании
```

**Уровень 2: Биологические образцы**
```
Дополнительное согласие на:
✓ Забор крови и слюны
✓ Анализ биомаркеров (BDNF, воспаление, метаболизм)
✓ Хранение образцов до 5 лет
✓ Повторные анализы при необходимости
```

**Уровень 3: Генетическое тестирование**
```
Специальное согласие на:
✓ ДНК анализ для полиморфизмов
✓ Эпигенетическое тестирование
✓ Возможность случайных находок
✓ Ограничения конфиденциальности
```

**Уровень 4: Цифровое мониторирование**
```
Согласие на непрерывный сбор:
✓ GPS локации и мобильности
✓ Использования телефона и приложений
✓ Голосовых характеристик
✓ Данных от носимых устройств
```

### 2.2 Процедура получения согласия

**Этап 1: Информирование (минимум 48 часов)**
- Предоставление письменной информации на родном языке
- Объяснение рисков и преимуществ участия
- Обсуждение альтернативных методов лечения
- Время на размышление и консультации

**Этап 2: Интерактивная сессия (1-1.5 часа)**
- Детальное объяснение процедур исследования
- Ответы на вопросы участника
- Тест на понимание (quiz) - обязательный проход 80%
- Документирование процесса

**Этап 3: Формальное согласие**
- Подписание согласия участником
- Подпись исследователя и свидетеля
- Предоставление копии участнику
- Возможность отзыва согласия в любое время

## 3. Защита конфиденциальности и данных

### 3.1 Технические меры безопасности

**Шифрование данных:**
- AES-256 для данных в покое
- TLS 1.3 для передачи данных
- End-to-end encryption для мобильных приложений
- Квантово-устойчивое шифрование для долгосрочного хранения

**Контроль доступа:**
```
Уровень доступа | Персонал                | Права доступа
----------------|-------------------------|------------------
Уровень 1       | Главный исследователь  | Полный доступ
Уровень 2       | Соисследователи        | Агрегированные данные
Уровень 3       | Аналитики данных       | Деидентифицированные
Уровень 4       | Техподдержка           | Только метаданные
```

### 3.2 Деидентификация данных

**HIPAA Safe Harbor метод:**
1. Удаление 18 типов прямых идентификаторов
2. Возрастные группы (>89 лет = "90+")
3. Географические коды не меньше первых 3 цифр ZIP
4. Даты с точностью до года

**Дополнительные меры:**
- k-анонимность (k ≥ 5) для всех датасетов
- l-разнообразие для чувствительных атрибутов
- t-близость для числовых переменных
- Дифференциальная приватность (ε ≤ 1.0)

### 3.3 Хранение и уничтожение данных

**Сроки хранения:**
```
Тип данных                    | Срок хранения | Место хранения
------------------------------|---------------|------------------
Клинические данные           | 7 лет         | Сертиф. дата-центр
Биологические образцы        | 5 лет         | -80°C биобанк
Генетические данные          | 25 лет        | Специал. репозиторий
Цифровые биомаркеры         | 3 года        | Облачное хранилище
```

**Процедуры уничтожения:**
- Физическое уничтожение носителей (DoD 5220.22-M стандарт)
- Криптографическое стирание ключей
- Сертифицированное уничтожение документов
- Протоколирование всех процедур уничтожения

## 4. Управление рисками

### 4.1 Классификация рисков

**Минимальный риск (<1:10,000):**
- Стандартные опросы и интервью
- Неинвазивные физиологические измерения
- Наблюдательные цифровые данные

**Низкий риск (1:10,000 - 1:1,000):**
- Забор крови (до 50 мл)
- Стресс-тестирование
- Раскрытие анонимизированных данных

**Умеренный риск (1:1,000 - 1:100):**
- Генетическое тестирование с возможными случайными находками
- Длительное психологическое тестирование
- Потенциальное нарушение конфиденциальности

### 4.2 Мониторинг безопасности

**Совет по мониторингу данных и безопасности (DSMB):**
- Независимая комиссия из 5 экспертов
- Ежемесячные обзоры безопасности
- Критерии раннего прекращения исследования
- Отчеты в IRB каждые 6 месяцев

**Процедуры сообщения о нежелательных событиях:**
- Немедленно: смерть, госпитализация, угроза жизни
- 24 часа: серьезные нежелательные события
- 7 дней: нарушение конфиденциальности
- 30 дней: непредвиденные проблемы

## 5. Специальные этические соображения

### 5.1 Случайные генетические находки

**Категории возвращаемых результатов:**
```
Категория | Примеры                    | Условия возврата
----------|----------------------------|------------------
1A        | BRCA1/2, Lynch синдром    | Обязательный
1B        | Фармакогенетика           | По запросу
2         | Полигенные скоры          | Только в исследованиях
3         | Неопределенное значение   | Не возвращается
```

**Процедура возврата результатов:**
1. Генетическое консультирование (обязательно)
2. Подтверждение в сертифицированной лаборатории
3. Клинические рекомендации
4. Психологическая поддержка при необходимости

### 5.2 Уязвимые группы

**Дополнительные защитные меры:**
- Несовершеннолетние: согласие родителей + согласие ребенка (≥7 лет)
- Когнитивные нарушения: оценка способности к согласию
- Беременные: исключение тератогенных процедур
- Заключенные: независимый адвокат интересов

### 5.3 Справедливость и инклюзивность

**Требования к репрезентативности:**
```
Группа                 | Минимальная квота | Обоснование
-----------------------|-------------------|------------------
Этнические меньшинства | 30%               | NIH Inclusion Policy
Женщины                | 50% ± 10%         | Гендерное равенство
Возраст >65 лет        | 20%               | Возрастное разнообразие
Низкий SES             | 25%               | Социальная справедливость
```

**Меры по обеспечению доступности:**
- Бесплатное участие для всех
- Компенсация транспортных расходов
- Перевод материалов на 8 языков
- Культурно-адаптированные протоколы

## 6. Надзор и аудит

### 6.1 Institutional Review Board (IRB)

**Состав комиссии:**
- Председатель (независимый этик)
- 2 медицинских исследователя
- 1 статистик/методист
- 1 юрист по медицинскому праву
- 2 представителя общественности
- 1 специалист по защите данных

**Процедуры пересмотра:**
- Первичное рассмотрение: полная комиссия
- Ежегодный пересмотр: обязательный
- Изменения протокола: экспедированный обзор
- Серьезные нарушения: внеочередное заседание

### 6.2 Внешний аудит

**Плановые инспекции:**
- FDA: каждые 2 года для интервенционных исследований
- EMA: по запросу регуляторных органов
- Institutional audit: ежегодно
- Международные стандарты: ISO 14155 сертификация

**Документооборот для аудита:**
- Master file со всеми процедурами
- Individual patient records (source documents)
- Adverse event logs
- Protocol deviation reports
